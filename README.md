# supplywatch-copilot
Project repository for MS AI Hackathon through Women In Cloud
Team Members:  Chichi Iwuorie, Ryan Rydalch, Suliat Ogunneye, Giselle Carvalho, & CJ Johnson

## Problem
Supply chain teams need a fast, trusted way to detect early signs of supplier risk. Today, signals are scattered across delivery logs, quality reports, and financial indicators, making early detection slow and inconsistent.

## Solution
This project unifies supplier signals, analyzes trends, explains the drivers of risk, and recommends mitigation actions through a structured Supplier Risk Brief delivered in Teams.

## Proposed Core Stack
- Microsoft Fabric for supplier data and analytics
- Azure AI Search for grounding with contracts/reports
- Azure OpenAI for risk explanation and recommendation generation
- Logic Apps / Power Automate for alerting
- Microsoft Teams for user delivery
